### 🚀 Highlighted Project

**[NFSMW HD Reflections](https://github.com/SNiTEBoBy/NFSMWHDReflections)**  
ASI plugin for Need for Speed: Most Wanted (2005)  
Control reflection cubemap resolution independently (up to 4K+), road reflection scaling, blur, tint.  
Built on Extra Options framework. \~Used by NFS modding community for modern visual upgrades.

- **Tech**: C++, DirectX 9 hooking, ASI loader  
- **Status**: Maintenance mode (stable, no breaking changes planned)
